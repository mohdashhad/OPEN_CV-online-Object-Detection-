🎯 Online Object Detection using OpenCV
📖 Project Description

The Online Object Detection project uses OpenCV and deep learning models to detect objects in real-time from a live webcam or online video stream. The system identifies and labels multiple objects with bounding boxes and confidence scores.
🚀 Features

Real-time object detection using webcam

Supports online / live video streams

Draws bounding boxes with class labels

Displays confidence scores

Fast and efficient frame processing
🛠️ Technologies Used

Python

OpenCV (cv2)

Pre-trained object detection model (YOLO / SSD / Haar Cascade)

NumPy
